# Typora 偏好设置功能对照与实现矩阵

本文档对 Typora 偏好设置（Preferences）的全部功能进行系统梳理，并与 ArborMark 当前实现进行全维度对照，明确已支持能力、本期增强落地项与未来规划。

---

## 一、模块功能全景对照表

### 1. 文件 (Files)

| Typora 功能项 | Typora 行为说明 | ArborMark 状态 | 落地实现说明 |
| :--- | :--- | :---: | :--- |
| **启动选项** | 重新打开上次使用的文件与目录 / 打开自定义目录 / 打开空文件 | ✅ 已支持 | 启动时自动恢复上次会话与工作区 |
| **切换文件时自动保存** | 切换文档或标签时，静默将未保存的修改写回磁盘 | 🚀 本期接入 | 切换文档与关闭时强制落盘未保存修改 |
| **恢复未保存的草稿** | 异常退出或崩溃时，从临时草稿区恢复 | ✅ 已支持 | 基于本地持久化和自动保存机制保证数据不丢失 |
| **默认文件扩展名** | 新建文件默认后缀：`.md` / `.markdown` 等 | 🚀 本期接入 | 新建文件若未输入后缀，自动补全首选扩展名 |
| **默认换行符 (EOL)** | 新文件换行符偏好：`LF (Unix)` vs `CRLF (Windows)` | 🚀 本期接入 | 偏好设置中可配置，保存及创建文件时遵循设置 |
| **最近使用的目录与历史** | 记录历史文件/文件夹，支持快速打开与清除历史记录 | 🚀 本期增强 | 偏好设置中提供一键「清除历史文件记录」功能 |
| **外部文件拖入行为** | 拖入文件/文件夹至窗口时：当前窗口打开 / 新窗口打开 / 插入内容 | 🚀 本期接入 | 支持配置外部文件拖入时的响应策略 |
| **大纲允许折叠和展开** | 侧边栏大纲支持折叠子章节 | ✅ 已支持 | OutlinePanel 支持点击箭头收起/展开各级子标题 |

| **未选中时复制/剪切整行** | 在光标处无文字选中时，按 `Cmd/Ctrl+C` 复制整行，`Cmd/Ctrl+X` 剪切整行 | 🚀 本期接入 | 优化 CodeMirror 与全局快捷键，提升高频编辑手感 |

| **打字机模式** | 键入或移动光标时光标始终保持在垂直视口中央 | ✅ 已支持 | `typewriterMode` 视口智能居中跟踪 |
| **专注模式** | 淡化非当前聚焦段落，高亮当前编辑区域 | ✅ 已支持 | `focusMode` 动态段落高亮聚焦 |
| **显示行号** | 编辑区左侧显示代码行号槽 | ✅ 已支持 | 源码模式下支持固定背景、平滑滚动的行号栏 |
| **自动换行** | 长文本软换行还是横向溢出滚动 | ✅ 已支持 | `prefs.lineWrapping` 支持折行与代码块换行 |

## 二、本期落地完成重点

本轮重点落地并补齐 Typora 核心体验项：
1. **偏好设置导航结构升级**：新增 **文件 (Files)** 专属选项卡（将换行符、默认扩展名、历史记录管理、自动保存归整）；
2. **新文件默认扩展名**（`.md` / `.markdown`）；
3. **默认换行符偏好**：`LF` vs `CRLF` 配置，并在文件生成/换行处理中生效；
4. **编辑器无选中时复制/剪切光标整行**：深度复刻 Typora / VS Code 丝滑操作；
5. **Ctrl / Cmd + 鼠标滚轮缩放字号**：按住修饰键滚动即可平滑调大/调小编辑器字号；
6. **无序列表符号偏好**（`-`、`*`、`+`）与 **代码块默认语言**；
7. **历史记录一键清除**；
8. **偏好设置与警告对话框一键重置为默认值**。
