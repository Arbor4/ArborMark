# 鸣谢

ArborMark 站在以下开源项目之上：

- **Milkdown / ProseMirror** —— 即时渲染编辑内核
- **CodeMirror 6** —— 源码模式编辑器
- **remark / unified** —— Markdown 解析与序列化
- **highlight.js** —— 代码语法高亮
- **KaTeX** —— 数学公式渲染
- **Mermaid** —— 图表渲染
- **DOMPurify** —— HTML 净化
- **Lucide** —— 图标
- **Tauri** —— 桌面壳与原生菜单
- **Zustand** —— 状态管理
- **Tailwind CSS** —— 样式工具

以及 CommonMark 与 GFM 社区维护的规范文档。

感谢每一位提交 issue 与 PR 的使用者。
