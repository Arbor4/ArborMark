# 自动保存、版本控制与恢复

## 自动保存

- 默认开启：停止输入约 0.8 秒后写盘（偏好设置 → 编辑器可关闭）。
- 手动保存 `⌘S` 始终可用；窗口标题的 `●` 表示有未保存修改。
- 切换文件前会先保存当前脏文档，避免丢失。

## 版本控制建议

ArborMark 不内置历史版本，推荐把笔记目录交给 Git：

```bash
cd ~/Notes
git init
git add .
git commit -m "notes: snapshot"
```

- 每次大改前提交一次；误改后用 `git diff` / `git checkout -- 文件` 恢复。
- 配合远程仓库（GitHub / Gitea）即获得异地备份。

## 误删恢复

- 文件树删除走**系统回收站**，可从回收站还原。
- 自动保存覆盖前的内容若已提交 Git，可用 `git show HEAD:路径` 找回。
- 桌面端崩溃后重启会恢复上次会话（偏好设置 → 通用 → 恢复会话）。

## 冲突提示

外部修改（如 Git  checkout、同步盘）与编辑器缓冲不一致时，
重新打开文件即可加载磁盘最新内容；未保存修改会先提示保存。
