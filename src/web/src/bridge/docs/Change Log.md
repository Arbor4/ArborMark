## 4.0.0

- 编辑态重构为 Milkdown 原位即时渲染：表格、代码块、公式、Front Matter 均在渲染结果上直接编辑。

- 全局搜索 `⌘⇧F`：跨文件命中、点击跳转并选中文件树节点。
- 大纲双向滚动联动，点击标题闪烁定位。
- 图片点击放大模态：缩放 / 平移 / 原始尺寸。
- 文内锚点与 [TOC] 目录跳转。
- 悬浮工具栏与透明状态栏，界面 chrome 可整体收起（`⌘\`）。
- 偏好设置：主题画廊、语法开关、设置导出 / 导入。
- Mac 原生菜单全量桥接。
