# Security Policy

## Supported Versions

We provide security updates for the latest major and minor release versions of ArborMark.

| Version | Supported          |
| ------- | ------------------ |
| 4.x.x   | :white_check_mark: |
| < 4.0.0 | :x:                |

---

## Reporting a Vulnerability

If you discover a potential security vulnerability in ArborMark, please report it privately rather than opening a public issue.

1. **Email us**: Send details to [Arbor4@users.noreply.github.com](mailto:Arbor4@users.noreply.github.com) with the subject `[SECURITY] ArborMark Vulnerability Report`.
2. **Provide information**:
   - Description of the vulnerability.
   - Steps to reproduce or proof-of-concept.
   - Affected platform (macOS, Windows, or Linux) and version.
   - Potential impact.
3. **Response time**: We will acknowledge receipt within 48 hours and work on a prompt remediation.
4. **Public Disclosure**: We request that you give us reasonable time to fix the issue before public disclosure.

Thank you for helping keep ArborMark and its users secure!
