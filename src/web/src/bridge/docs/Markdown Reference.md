# Markdown 语法参考

ArborMark 支持 CommonMark + GFM，并扩展了数学、图表与排版语法。

## 基础

| 语法 | 写法 | 说明 |
| --- | --- | --- |
| 标题 | `# H1` … `###### H6` | 亦支持 Setext（`===` / `---`） |
| 粗体 / 斜体 | `**粗**` / `*斜*` | 可嵌套组合 |
| 删除线 / 高亮 | `~~删~~` / `==高亮==` | GFM / 扩展 |
| 行内代码 | `` `code` `` | 双反引号可含反引号 |
| 链接 / 图片 | `[文本](url)` / `![alt](path)` | 点击图片可放大查看 |
| 引用 | `> 文本` | 支持嵌套与内部块级元素 |
| 分割线 | `---` | 单独一行 |

## 列表与任务

- 无序：`-` / `*` / `+`；有序：`1.`；缩进两空格嵌套。
- 任务列表：`- [x] 完成` / `- [ ] 待办`，渲染态可直接点击勾选。
- 松散列表：项目间空行保留段落间距。

## 表格

```markdown
| 列 A | 列 B |
| --- | :-: |
| 1 | 2 |
```

对齐：`---` 左、`:---:` 居中、`---:` 右。渲染态表格悬浮工具条可增删行列、移动与对齐。

## 代码块

围栏 ``` 加语言名（js / python / css / diff …）即时语法高亮；
浏览态点击代码块进入原位编辑，语言标签可点击修改。

## 数学与图表

- 行内 `$E=mc^2$`（偏好设置可开关），块级 `$$ … $$`。
- ```mermaid 流程图 / 时序图 / 类图 / 状态图 / 甘特图 / 饼图。
- ```flowchart.js 与 ```sequence 旧式图表语法。

## 扩展排版

- 上标 `^x^`、下标 `~x~`、脚注 `[^1]`、Emoji 简码 `:smile:`。
- GitHub 提示块：`> [!NOTE]` / `[!TIP]` / `[!WARNING]` / `[!IMPORTANT]` / `[!CAUTION]`。
- Front Matter：文件首部 `---` 包裹的 YAML，渲染为可编辑卡片。
- 目录：单独一行 `[TOC]` 自动生成可点击目录。
- 锚点：`<a id="top"></a>` 定义，`[回到顶部](#top)` 跳转；标题自动按 slug 生成锚点。
- 行内 HTML：`<kbd>` `<mark>` `<u>` `<sup>` `<sub>` `<abbr>` 等；块级 `<details>` 折叠块。
