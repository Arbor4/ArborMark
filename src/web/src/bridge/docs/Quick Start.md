# 快速入门

欢迎使用 ArborMark —— 一款「所见即所得」的本地 Markdown 编辑器。

## 三步开始

1. **打开文件夹**：`⌘O` 选择你的笔记目录，左侧文件树会列出全部 Markdown 文件。
2. **开始写作**：点击或 `⌘N` 新建文档。编辑区即时渲染：输入 `# ` 得到标题、`- ` 得到列表、``` 得到代码块。
3. **保存**：`⌘S` 保存；默认开启自动保存，状态栏与窗口标题会提示未保存状态。

## 界面速览

- **活动栏**（最左）：文件 / 大纲 / 搜索 / 外观 / 偏好设置。
- **侧边栏**：文件树或文档大纲，`⌘1` / `⌘2` 切换，`⌘\` 收起全部 chrome。
- **编辑区**：默认即时渲染（编辑态），`⌘/` 切换纯源码模式。
- **悬浮工具栏**：编辑区底部居中，左下角按钮可收起；源码切换按钮旁。
- **状态栏**：文件名、字数、预计阅读时长。

## 常用快捷键

| 操作 | 快捷键 |
| --- | --- |
| 新建 / 保存 / 打开文件夹 | ⌘N / ⌘S / ⌘O |
| 快速打开文件 | ⌘P |
| 文件内搜索 / 替换 | ⌘F / ⌘R |
| 全局搜索 | ⌘⇧F |
| 编辑 / 源码切换 | ⌘/ |
| 专注模式 | ⌘⇧D |
| 偏好设置 | ⌘, |
