# 在 ArborMark 中使用图片

## 插入图片

- **拖拽**：把图片文件拖入编辑区，自动复制到文档目录并插入相对路径。
- **粘贴**：截图后直接 `⌘V`，保存为附件并插入。
- **工具栏 / 菜单**：插入 → 图片，选择本地文件。
- **手写**：`![描述](images/photo.png)`。

## 路径规则

- 默认使用**相对当前文档**的路径（偏好设置 → 图片 → 使用相对路径）。
- 移动文档时建议连同图片目录一起移动，保持相对关系。
- 网络图片直接使用 `https://` 地址。

## 查看与放大

- 编辑态与源码态都会渲染图片缩略图（最高 480px）。
- **点击图片**打开放大模态：滚轮缩放、拖拽平移、双击切换原始 / 适应尺寸、`Esc` 关闭。
- 图片缺失时显示占位块，点击可查看原始路径便于排查。

## 管理

- 偏好设置 → 图片：相对路径、URL 自动转义等开关。
- 右键图片可复制路径 / 在文件夹中显示（桌面端）。
